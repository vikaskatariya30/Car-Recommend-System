# 🚗 Car Recommendation System

A content-based car recommender built with Python and Streamlit. Enter a car model and get the five most similar cars, based on brand, body type, fuel type, transmission, engine size, mileage/range and price.

## Features

- Content-based filtering using **cosine similarity**
- Text features (name, brand, body type, fuel, transmission) processed with **Porter stemming** and **CountVectorizer**
- Numeric features (seating capacity, engine cc, mileage/range, prices) scaled with **MinMaxScaler**
- Simple **Streamlit** web UI returning the top 5 similar cars

## How It Works

1. **Data cleaning**: drops unused columns (`rto_tax_rs`, `insurance_rs`, `other_charges_rs`, `segment`).
2. **Mileage bucketing**: mileage/range is grouped into buckets, with separate ranges for electric cars (km range) and fuel cars (km/l).
3. **Tag creation**: `name + brand + body_type + fuel_type + transmission` is lowercased and stemmed into a `tags` column.
4. **Vectorization**: tags go through `CountVectorizer` (max 5000 features, English stop words) and are combined with the MinMax-scaled numeric columns.
5. **Similarity**: a cosine similarity matrix is computed across all cars and saved as `similarity.pkl`.
6. **Recommendation**: for a chosen car, the 5 highest-similarity cars (excluding itself) are returned.

## Dataset

`car.csv` contains 133 cars with these columns:

| Column | Description |
|---|---|
| `name` | Car model name |
| `brand` | Manufacturer |
| `body_type` | Hatchback, Sedan, SUV, Van, etc. |
| `fuel_type` | Petrol, Diesel, Electric, etc. |
| `transmission` | Manual, AMT, Automatic, etc. |
| `seating_capacity` | Number of seats |
| `engine_cc` | Engine displacement |
| `mileage_or_range` | Mileage (km/l) or range (km) for EVs |
| `ex_showroom_price_rs` | Ex-showroom price (₹) |
| `on_road_price_rs` | On-road price (₹) |
| `mileage_range_bucket` | Bucketed mileage/range |
| `tags` | Processed text used for vectorization |

## Getting Started

### Prerequisites

- Python 3.8+

### Installation

```bash
git clone https://github.com/vikaskatariya30/Car-Recommend-System.git
cd Car-Recommend-System
pip install streamlit pandas numpy scikit-learn nltk seaborn matplotlib jupyter
```

### Generate the similarity matrix

`app.py` loads `similarity.pkl`, so generate it first. Open `model_training.ipynb`, run all cells, then add and run this final cell:

```python
import pickle
pickle.dump(similarity, open('similarity.pkl', 'wb'))
```

> The notebook reads the raw `car_dataset.csv` and writes the cleaned `car.csv`. If you only want to run the app, make sure `car.csv` and `similarity.pkl` are both in the project root.

### Run the app

```bash
streamlit run app.py
```

Then open the local URL shown in the terminal (usually http://localhost:8501).

## Usage

1. Type a car model exactly as it appears in the dataset, e.g. `Maruti Alto K10`.
2. Click **recommend**.
3. The five most similar cars are shown side by side.

## Known Limitations

- The search box needs an **exact match** on the `name` column; unknown names will raise an error.
- Only car names are displayed (no images or specs yet).
- The dataset is small (133 cars), so recommendations are limited to what it covers.
